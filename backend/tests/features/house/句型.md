# house 句型模型

## 實體概述

- **性質**: Aggregate（houses）+ 從屬 Aggregate（votes）
- **攜帶狀態**: 網址（唯一、不可改）、總租金（>0）、備註（不可改）、房東狀態、看房狀態、新增時間；投票（網址 × 姓名 → 是 / 否）
- **Invariant 清單**:
  - 每位成員對同一房屋只有一票
  - 投票結果：≥2 是 → 列入考慮；≥2 否 → 不考慮；其餘 → 投票中
  - 分租租金 = round(總租金 × 權重 ÷ 33)，差額由 ruby（權重最高）吸收；分租租金 > 個人最高預算 → 超出預算
  - 列表排序：總租金由低到高，相同時新增時間新的在前
  - 刪除房屋 → 其投票一併刪除

## 測試分析

> 共用測試資料：成員 ruby(12000/12)、joyce(10000/10)、cya(11000/11)；房屋網址用 `https://rent.example/a`、`/b`… 等。

### 新增房屋

**等價類劃分**: 參數齊全 / 缺網址 / 缺總租金 / 未填備註（合法）；總租金 ∈ {正整數, 0, 負數, 小數, 非數字}。
**邊界值分析**: 總租金 = 1（最小合法）、0（最大不合法）。
**狀態轉移**: 未登入 → 拒絕；網址已存在 → 拒絕。
**組合覆蓋**: 不適用（各參數驗證獨立）。
**錯誤推測**: 網址只差結尾 `/` 被誤判重複（Q14 補問：完全相同才算）；新房屋被誤帶投票。

### 刪除房屋

**等價類劃分**: 房屋 ∈ {存在, 不存在}。
**邊界值分析**: 不適用。

**組合覆蓋**: 不適用。
**錯誤推測**: 誤刪其他房屋；刪除後殘留投票。

### 投票是否列入考慮

**等價類劃分**: 選擇 ∈ {是, 否, 未提供, 其他值}；房屋 ∈ {存在, 不存在}。
**邊界值分析**: 「是」票數 1（未達門檻）/ 2（達門檻，第三人未投）。
**狀態轉移**: 未投 → 投是；已投否 → 改是（覆蓋）；列入考慮 → 改票後移出。
**組合覆蓋**: 不同成員票的組合（見查詢房屋列表的投票結果分析）。
**錯誤推測**: 改票產生第二張票；第三人未投時不判定。

### 查詢房屋列表

**等價類劃分**: 有房屋 / 無房屋；投票組合 7 類（無票、1是、2是、2否、1是1否、2是1否、1是2否）。
**邊界值分析**: 分租 = 預算（33000 → 剛好等於，不算超出）；33001（ruby 吸收 +1 後 12001 > 12000）；30002（ruby 吸收 −1）；36000（三人皆超出）。總租金相同時的排序。
**狀態轉移**: 未登入 → 拒絕。
**組合覆蓋**: 投票組合 × 我的投票（是 / 否 / 未投票）。
**錯誤推測**: 回應洩漏他人投票；四捨五入後加總 ≠ 總租金；同租金排序不穩定。
