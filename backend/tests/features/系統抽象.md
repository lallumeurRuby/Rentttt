# 系統抽象

> Boundary：**web-backend**（FastAPI + PostgreSQL，Behave E2E）
> 來源：`member/*.feature`、`house/*.feature`（Phase 01 Rules）+ `specs/erm.dbml`（Phase 02）

## 實體清單

| 實體 | 性質 | 攜帶狀態摘要 | 對應 features subfolder |
|------|------|-------------|------------------------|
| 成員（members） | Aggregate | 姓名（唯一、登入識別）、個人最高預算、分租權重；預建 3 筆，不可修改 | `member/` |
| 房屋（houses） | Aggregate | 網址（唯一、不可改）、總租金（>0，可改）、備註（可改、可留空）、房東狀態、看房狀態、新增時間 | `house/` |
| 投票（votes） | Aggregate（從屬於房屋） | 房屋 × 成員 → 是 / 否；每人每屋一票；隨房屋刪除 | `house/` |
| 登入憑證（JWT） | Gateway（無狀態） | 由 登入 操作簽發，後續操作以此識別成員 | `member/` |

## 操作全景

| 操作 | 所屬實體 | 行為分類 | 需登入 | 輸入參數 | 回傳 |
|------|---------|---------|-------|---------|------|
| 查詢成員列表 | 成員 | Query | 否 | — | 成員姓名清單 |
| 登入 | 成員 / 登入憑證 | Query（POST，不改變狀態，回傳憑證） | 否 | 姓名 | token + 姓名、個人最高預算、分租權重 |
| 新增房屋 | 房屋 | Creation | 是 | 網址、總租金（必填）、備註（選填） | — |
| 編輯房屋 | 房屋 | Mutation | 是 | 房屋、總租金（必填）、備註（選填，留空即清空） | — |
| 刪除房屋 | 房屋（+ 投票） | Mutation（Deletion） | 是 | 房屋 | — |
| 投票是否列入考慮 | 投票 | Mutation（Upsert） | 是 | 房屋、投票選項 | — |
| 變更房東狀態 | 房屋 | Mutation | 是 | 房屋、房東狀態 | — |
| 變更看房狀態 | 房屋 | Mutation | 是 | 房屋、看房狀態 | — |
| 查詢房屋列表 | 房屋 + 投票 + 成員 | Query | 是 | — | 房屋清單（含分租試算、超出預算、投票結果、我的投票） |
| 查詢考慮列表 | 房屋 + 投票 + 成員 | Query | 是 | — | 列入考慮的房屋清單（含分租試算、超出預算） |

## 系統前置狀態拆解

> 從所有操作的 Rule（前置）反推。每個葉子部件對應一個 Given 句型。

| 部件 | 資料型別 | 建置方式 | 內部子結構 | Given 句型 |
|------|---------|---------|-----------|-----------|
| 成員 | members 列 | Data Table（States Prepare） | 無 | `Given 系統中有以下成員：` |
| 房屋 | houses 列 | Data Table（States Prepare） | 無（狀態欄可省略 → 用 DB 預設值） | `Given 系統中有以下房屋：` |
| 投票 | votes 列 | Data Table（States Prepare） | 無；以「網址 + 姓名」作為複合 Key | `Given 系統中有以下投票：` |
| 登入狀態 | JWT token | 前置操作（Operation Invocation，經 登入 API） | 無 | `Given 成員 "<姓名>" 已登入` |

> 「未登入」= 不執行 `已登入` 步驟，以無憑證呼叫操作。

## 行為分類與句型骨架

### Creation（新增房屋）

**When**：`When 成員 "<姓名>" 新增房屋：`（接 Data Table：網址 / 總租金 / 備註；備註可留空）
**Then（成功）**：`Then 操作成功` + `And 系統中應有以下房屋：`（States Verify）
**Then（失敗）**：`Then 操作失敗，violation_type 為 "<violation>"`

### Mutation（編輯房屋 / 刪除 / 投票 / 變更房東狀態 / 變更看房狀態）

**When**：`When 成員 "<姓名>" <動詞> 房屋 "<網址>" <參數>`
**Then（成功）**：`Then 操作成功` + States Verify（`房屋 "<網址>" 應為：` / `系統中應有以下投票：` / `系統中不應有房屋 "<網址>"`）
**Then（失敗）**：`Then 操作失敗，violation_type 為 "<violation>"`

### Query（查詢成員列表 / 登入 / 查詢房屋列表 / 查詢考慮列表）

**When**：`When 成員 "<姓名>" 查詢<目標>` / `When 訪客查詢成員列表` / `When 以姓名 "<姓名>" 登入`
**Then（成功）**：`Then 操作成功` + `And 查詢結果應為：`（Read Model Verifier，Data Table 依序比對）
**Then（失敗）**：`Then 操作失敗，violation_type 為 "<violation>"`

## 共用契約

### Postcondition 模式

| 模式 | 適用操作 | 驗證方式 |
|------|---------|---------|
| 成功只回 `success: true`，副作用以 DB 驗證 | 所有 Creation / Mutation | `操作成功` + aggregate-then |
| 列表以 Data Table 驗證「筆數 + 順序 + 內容」 | 查詢房屋列表、查詢考慮列表、查詢成員列表 | readmodel-then |
| 分租租金 = round(總租金 × 權重 ÷ 33)，差額歸權重最高者（ruby） | 查詢房屋列表、查詢考慮列表 | readmodel-then（同一組計算欄位） |
| 投票結果 = ≥2 是→列入考慮；≥2 否→不考慮；其餘→投票中 | 查詢房屋列表（顯示）、查詢考慮列表（過濾） | readmodel-then |

### Violation 模式

> violation_type 直接使用 Phase 01 Q18 確認的中文錯誤訊息，跨 feature 共用。

| 前置條件 | violation_type | 適用操作 |
|---------|---------------|---------|
| 未登入 | `請先登入` | 新增 / 編輯 / 刪除 / 投票 / 房東狀態 / 看房狀態 / 房屋列表 / 考慮列表 |
| 姓名不是成員 | `查無此成員` | 登入 |
| 房屋不存在 | `房屋不存在` | 編輯 / 刪除 / 投票 / 房東狀態 / 看房狀態 |
| 必要參數缺漏 | `必要參數未提供` | 登入 / 新增 / 編輯 / 刪除 / 投票 / 房東狀態 / 看房狀態 |
| 總租金非正整數 | `總租金必須為正整數` | 新增 / 編輯 |
| 網址與現存房屋相同 | `網址已存在` | 新增 |
| 狀態不在清單中 | `狀態不合法` | 房東狀態 / 看房狀態 |
| 投票選項非「是 / 否」 | `投票選項不合法` | 投票 |

## 共用句型

> Stage 2.5 萃取：member/ 與 house/ 句型.md 中文字完全相同的句型。

| # | 句型 | Handler | 使用 domain |
|---|------|---------|------------|
| S-G1 | `Given 系統中有以下成員：`（姓名 / 個人最高預算 / 分租權重） | aggregate-given | member、house |
| S-T1 | `Then 操作成功` | success-failure（骨架既有 common step） | member、house |
| S-T2 | `Then 操作失敗，violation_type 為 "{violation}"` | success-failure（骨架既有 common step） | member、house |

## 變異點索引

| 實體 | 特有行為 | 需要的專屬句型類別 |
|------|---------|------------------|
| 成員 | 不需登入的查詢；登入簽發憑證 | 訪客 Query、登入 Query、`已登入` 前置操作 |
| 房屋 | 列表的衍生欄位（分租試算、超出預算、投票結果、我的投票）、排序 | Read Model Data Table（多衍生欄位） |
| 投票 | Upsert（改票）、匿名（只回傳自己的票）、隨房屋 cascade 刪除 | 投票 States Prepare / Verify（網址 + 姓名 複合 Key） |
